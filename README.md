# SqueezeNative v1.0

**SqueezeNative** is a lightweight, portable desktop utility for Windows designed to compress high-resolution images, videos, and PDF documents in seconds.

---

## Quick Start

1. Extract all files from `SqueezeNative.zip` to any folder on your computer.
2. Double-click `SqueezeNative.exe` to launch the application.
3. Drag and drop any supported media files or entire folders into the application window to launch simultaneous batch compression.

> **Windows SmartScreen Note:**  
> If Windows displays a warning (*"Windows protected your PC"*), click **More info** -> **Run anyway**. This happens on portable executables without an enterprise code-signing certificate.

---

## Supported Formats

- **PNG Images:** `.png` (lossy palette reduction)
- **JPEG / WebP:** `.jpg`, `.jpeg`, `.webp`
- **Video Files:** `.mp4`, `.mov`, `.avi`, `.mkv` (H.264 optimization)
- **PDF Documents:** `.pdf` (stream & image compression)
- **Batch Proccesing:** Drop multiple files or folders at once. The app dynamically processes items in parallel, utilizing 100% of your native CPU power with responsive real-time progress logs
